# IN1M-Pronunciation-Vocabulary-Diagnostic
Diagnóstico interactivo de vocabulario y pronunciación de IN1M. Descubre qué palabras ya usas, cuáles reconoces y cuáles son nuevas. Practica pronunciación, escucha modelos, repite, corrige errores y mide tu progreso. Convierte vocabulario pasivo en inglés que realmente puedes usar.
